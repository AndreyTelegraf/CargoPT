# CargoPT

CargoPT is a platform that connects customers with transport companies across Portugal.

Customers submit one structured transport or moving request and receive multiple offers from suitable carriers. Transport companies receive relevant requests based on their service area and vehicle capabilities.

Website:
https://cargopt.pt/

## Main features

- One request sent to multiple suitable carriers
- Structured moving and transport requests
- Carrier matching based on location and vehicle capabilities
- Request tracking
- Portuguese, English and Russian interface
- SEO knowledge base about moving and transport in Portugal

## Project structure

- `app/` — application code
- `content/` — SEO guides and structured content
- `docs/` — architecture and technical documentation
- `migrations/` — database migrations
- `scripts/` — maintenance and build scripts
